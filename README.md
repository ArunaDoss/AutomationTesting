# AutomationTesting

A Java-based automation testing framework using TestNG and Allure for reporting.

## Overview
- Implements Selenium/TestNG automation for UI testing.
- Captures screenshots and generates clear test reports.

## Features
- Java + TestNG framework with Maven configuration (`pom.xml`).
- Test report integration via Allure.
- Structured folder layout including `src/test/java`, `test-output`, `allure-results`, and `Screenshots`.

## Getting Started
1. Clone the repo.
2. Run `mvn test` to execute tests and generate reports.
3. View Allure dashboard using `allure serve <allure-results-directory>`.

## Technologies
- Java, TestNG, Maven, Allure, Selenium WebDriver (if used), HTML/CSS/JavaScript for test assets.
